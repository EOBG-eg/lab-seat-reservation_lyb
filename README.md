# 실습실 좌석 예약 · 파일 보호 안내 시스템

> 소프트웨어개발 2회차 프로젝트 (캠퍼스 문제 해결) · 2026.10 · 개인 개발 (경동대학교 소프트웨어학과 이유빈)

실습실 PC 좌석을 시간대별로 예약하고, 예약·사용 전에 그 자리(PC)에 남겨진 파일 주의사항을 확인하게 하는 Flask 웹 시스템입니다.
모르는 사람이 내 파일을 어지럽혀 놓은 경험에서 출발했습니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 학생 | 7자리 학번 회원가입·로그인, 시간대별 좌석 예약·취소·사용 시작·반납 (1인 1좌석), 사용 중인 자리는 대기열 등록 → 자리가 비면 선착순 자동 승격·알림 |
| 자리별 주의사항 | 여러 명이 남길 수 있고, 예약·사용 전 확인 창에서 동의해야 진행. 작성자 알림, 작성자·관리자만 삭제 |
| 관리자 | 시간대별 좌석 현황, 강제 회수, 감사 로그 열람·필터, 휴대폰 접속 QR, 시연용 시계 |
| 자동 정리 | 시간대가 끝나면 사용 중인 자리는 자동 반납, 예약만 한 자리는 예약 만료 |

## 기술 스택

Python · Flask · SQLite · Jinja2 · Tailwind CSS(CDN) · qrcodejs · cloudflared(외부 접속)

## 실행 방법

```
python -m pip install flask
python app.py
```

브라우저에서 http://localhost:5000 에 접속합니다. 데이터베이스(`lab_system.db`)는 처음 실행할 때 자동으로 만들어집니다.
휴대폰·외부 접속 방법은 `설치및실행.txt`를 참고하세요.

시연용 계정: 관리자 `admin` / `admin1234`, 학생은 로그인 화면의 빠른 로그인 버튼(비밀번호 `1234`). 모두 시연용 가상 계정입니다.

## 검증

Flask 테스트 클라이언트 + 시계 조작 회귀 테스트 32건, 무작위 조작(40회 × 120회) 불변 조건 점검, 동시 접속 부하 테스트, 휴대폰·다른 실습실 실기기 확인.
